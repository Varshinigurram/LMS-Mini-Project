# LMS Project Overview

## Purpose

The Library Management System is planned as a centralized system for managing library resources and transactions.

## Main Users

- Student
- Librarian
- Administrator

## Planned Functions

1. User authentication
2. Book catalog management
3. Member management
4. Book issue
5. Book return
6. Fine calculation
7. Search
8. Reports

## Current Status

This repository currently contains the initial project structure created for the Software Engineering configuration management laboratory.
